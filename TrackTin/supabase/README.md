# Supabase

Ejecuta `tracktin_schema.sql` en el SQL Editor y después `tracktin_lists.sql` para crear las listas personalizadas y sus permisos. Despliega la función con `supabase functions deploy tracktin-tmdb` y guarda el token con `supabase secrets set TMDB_API_TOKEN=...`. Configura en Auth las URLs de redirección del sitio de GitHub Pages.
